## Study workflow

- Study Modules 1–7 in order, and write down any implementation assumptions
  stated by a question.
- Trace defined C programs by hand. Undefined behavior has no predictable
  output.
- Use a compiler to check syntax and explore a particular implementation, but
  distinguish those observations from guarantees made by the C standard.
- Defer Module 8 until after GATE 2027, as specified in the syllabus.

Exact type sizes, alignment, memory layout, and some expression details are
implementation-dependent unless the question provides assumptions.
